# 등가 판 계산 보고서 — SPHX-example

생성: `calc/plate_model.py`, 입력: assumed defaults (docs/05 §5), 날짜 2026-09-09. 단위 mm–N–MPa. 정의·근거: docs/05 (형상), 06 (채택식), 07 (β 회전), 09 (등가 두께·GENS·응력 복원).

## ⚠ 경고·확인 필요

- t_min 미입력 → 공칭 두께로 계산. 성형 후 두께 감소(능선부 5~15% 통상)를 반영하지 않음
- t/R_min = 0.40 > 0.2: 쉘 이론 유효범위 밖. 강성은 유지, 능선 응력은 D단계 솔리드 FE 보정계수 필요 (09 §5)
- t_b/p = 0.41: 등가 판 두께가 피치와 같은 차수. 등가 판 FE 요소 크기 ≥ 2p, 스팬/t_b ≫ 10 을 확인하고 횡전단(SSPE) 감도를 본다
- 판 유효 주름 영역 크기(D_e 또는 W_e) 미입력 → apex/테두리 보정, 전체 판 합력 산정은 이 보고서 범위 밖

- 면내 구속을 fixed 로 바꾸면 max σ_vM = 59.1 MPa (free = 거시 N_x = 0, 굽힘 지배; fixed = 아치 작용, 하한). 실제는 두 값 사이이며 free 를 설계값으로 쓴다.
- 균질화 D11 연속보 근사(스팬 p)로 같은 문제를 풀면 VAM 최대 σ_vM 50.0/100.0 MPa (중앙/지지) — 프레임 해 173.9 MPa 를 크게 과소평가하므로 1피치 스팬에는 균질화 판을 쓰지 않는다.
- 접촉점: F = 93.5 N, 교차각 120°, 외면 반경 1.80 mm → Hertz p0 = 3612 MPa (반타원 평균 반축 0.111 mm). p0 > 1.6·항복강도 이면 접촉점 국부 항복(접촉부 평탄화) — 통상적 현상이나 피로·마모 검토 항목.

## 8. 한계

- 판 본체(주기 영역) 전용. apex·테두리·포트·용접부는 상세 FE 보정계수 필요 (docs/08 §2).
- 선형 탄성, Kirchhoff 등가 판. 국부 좌굴·접촉·소성은 범위 밖.
- 판축 합력은 사용자가 별도 산정하여 `load_cases` 로 입력한다. 압력차는 `loads.dP_max` 를 주면 C-4 폐형식으로 자동 평가한다(§7b).
